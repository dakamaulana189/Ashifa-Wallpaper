ASHIFA — LIVE WALLPAPER

Isi folder:
- index.html       Halaman wallpaper
- style.css        Tampilan, ukuran, dan posisi jam/tanggal
- script.js        Jam real-time, tanggal Indonesia
- assets/ashifa.png  Desain Canva statis 1920 x 1080

CARA MENCOBA
1. Ekstrak folder Ashifa-Wallpaper jika masih berbentuk ZIP.
2. Buka index.html di Chrome/Edge untuk melihat preview.
3. Pastikan jam dan tanggal berada di kotak krem bagian kanan bawah.

CARA MEMASANG DI LIVELY WALLPAPER
1. Buka Lively Wallpaper.
2. Pilih tombol tambah wallpaper (+) atau Add Wallpaper.
3. Pilih Browse / Select File, lalu pilih index.html di folder ini.
4. Beri nama wallpaper, misalnya "Ashifa", lalu tambahkan.
5. Terapkan wallpaper ke desktop.

CATATAN
- Desain Canva tidak dianimasikan; hanya jam, dan tanggal
- Jam memakai waktu lokal Windows dan format 24 jam.
- Target desain: 1920 x 1080 (16:9).

PENYESUAIAN POSISI
Jika jam belum tepat di tengah kotak krem, buka style.css dan ubah:
--clock-x: 61.5%;
--clock-y: 80.6%;

Naikkan nilai --clock-x untuk menggeser jam ke kanan; turunkan untuk ke kiri.
Naikkan nilai --clock-y untuk menggeser jam ke bawah; turunkan untuk ke atas.
